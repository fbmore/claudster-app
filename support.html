Installing

  1. Download the latest .dmg from Releases, drag Claudster to Applications and open it. It needs macOS 14 or later, on Apple silicon or Intel.
  2. The welcome guide opens after the splash. Its first step, Install, connects Claude Code. You can also do it any time in Settings › Claude Code › Install.
  3. Claudster lives in the menu bar. Its mascot sleeps while everything is done and wakes when a session is busy or needs you; a dot beside it shows the most urgent state across your projects.

A project doesn't show up

  • Claudster looks for Git repositories up to two levels inside the folders in Settings › Folders (by default ~/Developer). Add the folder that holds your projects.
  • A card appears once a Claude Code or Codex session in that project has reported. Sessions already running start reporting after you install, with no restart needed.
  • Check that Settings › Claude Code says Installed and shows all hooks. If you moved the app, choose Repair Hooks in the menu.

Clicking a project doesn't bring its terminal forward

  • macOS needs to let Claudster control your terminal. Click Grant Automation Permission… in Settings › Claude Code and allow it, or turn it on in System Settings › Privacy & Security › Automation › Claudster.
  • Focus works with Terminal, iTerm and tmux.

Opening the dashboard on your phone

  • Choose Show Phone QR Code… in the menu and scan it with your phone's camera. Your phone must be on the same Wi-Fi as your Mac the first time. After that it reaches your Mac from anywhere, through Claudster's encrypted relay. If your iPhone is signed in to the same Apple Account with Keychain sync (iCloud › Passwords) on, you can skip the code: your Mac shows up under From your Keychain in the phone app, at home or away.
  • If it doesn't load, check that Allow access from other devices on this network is on in Settings › General, and that macOS allowed Claudster on the local network (System Settings › Privacy & Security › Local Network).
  • The link carries a private key. If someone else gets it, they can see your sessions; keep it to yourself.

Codex sessions

Claudster shows OpenAI's Codex CLI sessions on the same board. In Settings › Claude Code, under Codex, click Install: the hooks go in ~/.codex/hooks.json beside your own, and the status skill in ~/.agents/skills/. Codex asks you to trust new hooks once: type /hooks in a Codex session. It needs a Codex CLI version with hooks, and a ~/.codex folder, which Codex makes the first time it runs.

Notifications

Claudster notifies you when a session starts waiting on you or fails. Change how they appear in System Settings › Notifications › Claudster.

Queue and Send now

Type a task on a card and choose Queue: the session receives it at its next turn. Send now wakes an idle session by typing one fixed line into its terminal. It never types into a session that is waiting on a question, so it can't answer a prompt for you.

A queued task stays editable until the session picks it up: click it on the card to change the text or its attachments. A task can be up to 20,000 characters.

The + after the project tabs starts a new session in any project: Claude Code, or Codex if you choose it under New sessions run in Settings › Claude Code.

Slash commands

Type / at the start of a reply box, on the dashboard or in the iPhone app, to see the session's commands: the agent's own (such as /compact), your commands and skills, the project's, and installed plugins'. The agent's own commands are typed straight into its terminal; the rest are queued like any task. If the list can't load (the Mac is out of reach, or the session's folder can't be read), the box says why and tries again.

Ask several projects at once

Choose Ask all on the dashboard (on the iPhone, the megaphone tile), pick the projects, and type one request. Each project's own session gets it and works on it there, so the answers come back on each card. With no project picked it goes to all of them.

Previews, sketches and mark-up

  • Preview Site, in a card's ⋯ menu, opens the site the project serves, live and zoomed out, in a small window. Select (⇧⌘C) lets you click an element and add a note; it goes to the card. On the iPhone, the preview streams live: tap to click, drag to scroll, pinch to zoom. If nothing is serving the project, ask the session to start it.
  • The pencil in a card's reply box opens a sketch sheet over the screen, with four pens, an eraser and a Paper slider from white to clear for drawing over what's behind it. Drag a box with the blur tool over anything private: it's pixelated in the picture itself, so it never reaches the session.
  • Click an attached image or PDF, then the pencil, to mark it up before sending. On the iPhone, tap an attached image to crop or mark it up.

Share to Claudster from your iPhone

In any app, tap Share and choose Claudster. Pick a project's terminal window, or New window to start a Claude Code session with it, then Send. Images, files, links and text go to your Mac and are queued for that session. If Claudster isn't in the share sheet, scroll to the end of the app row, tap More and turn it on.

Dictate a task

  • On macOS 26 or later, click the microphone in a card's task field, or press ⌃⌥M from any app. If a Terminal or iTerm tab running a session is in front, Claudster listens for that session.
  • Speak, then choose Send (or press Return, or say "send"): the text is queued and the session is woken to pick it up. Edit puts the text in the field instead; Cancel (Esc, or say "cancel") drops it.
  • If nothing happens, allow Claudster in System Settings › Privacy & Security › Microphone. Change or clear the shortcut in Settings › General.
  • In a browser on your Mac (the dashboard at localhost), the microphone works too: the browser asks for permission the first time. If you said no, allow the microphone for that page in the browser's site settings.
  • On your phone, tap the task field and use the microphone on your keyboard. Browsers keep the microphone from pages on a local Wi‑Fi link, so the page's own mic button only points you there.

Tile terminals side by side

  • Pick one or more project tabs on the dashboard (⌘-click picks several), then choose Tile. Their Terminal windows fill one screen: halves for 2, columns for 3, quarters for 4. With more than one display, Tile asks which.
  • While tiled, focusing any one of them brings the whole group forward. Untile puts every window back where it was and returns tabs to the windows they came from.
  • Tabs that share a window need Accessibility to come apart and go back: allow Claudster in System Settings › Privacy & Security › Accessibility. Tile works with Terminal.

Icons, colors and screenshots

  • Claudster finds each project's icon (an Xcode app icon, a favicon, or .claude/icon.png if you add one) and its brand color. Open a card's details on the dashboard to pick a different one.
  • When screenshots are on (Settings › Cards), Claude attaches screenshots of what it built, and cards also show images from the session.

Terminal tab labels and folder icons

Both are optional, in Settings › Claude Code. Label Terminal tabs titles each Terminal tab with its state and project. Settings shows how to shorten Terminal's own tab titles so the label fits. Put each project's icon on its folder gives project folders their app icon in Finder and in Terminal's title bar.

Uninstalling completely

  1. In Settings, turn off Put each project's icon on its folder, Label Terminal tabs and Open Claudster at login.
  2. In Settings › Claude Code, click Remove to take Claudster's hooks and skill out of Claude Code, and the same for Codex if you installed it there.
  3. Quit Claudster and move it to the Trash.
  4. Delete ~/Library/Application Support/Claudster and ~/Library/Caches/Claudster.
  5. Optionally, delete the .claude/status.json, events.jsonl, queue.json and screenshots/ files in your projects, and the Claudster lines in ~/.config/git/ignore.
